# tingting-stickers

婷婷和哥哥的专属表情包仓库，只收录公开表情包素材。

## 第一批素材

- `assets/luobo-01/`：绿萝卜·第一弹，16 张
- `assets/zhegou-01/`：这狗·第一弹，24 张
- `assets/zhegou-02/`：这狗·第二弹，24 张
- `assets/xiaotudou-01/`：兔番番·小兔豆，19 张（含 GIF 动图）

共 83 张。

## 索引

`index.json` 记录每张图的：

- 英文语义文件名
- 角色与系列
- 中文情绪／用途
- 仓库相对路径
- 是否为动图

## 使用流程

1. 按情境检索 `index.json`。
2. 从 GitHub 取回需要的少量图片。
3. 在最终回复中以本地图片方式展示。

不使用远程 Markdown 直链展示，也不把私人照片、自拍或聊天截图放进公开仓库。
